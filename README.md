# GoPet

Crie um marketplace de transporte de pets na cidade de São Paulo, semelhante a um app de corridas. Inclua uma experiência inicial completa e responsiva para tutores solicitarem corridas e motoristas parceiros visualizarem/aceitarem chamadas. Use português do Brasil e uma identidade visual acolhedora, segura e moderna. Habilite Lovable Cloud para suportar contas, perfis de tutor/motorista, solicitações de corrida e status.

This project was built with [Lovable](https://lovable.dev).
